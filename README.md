An invented passport spread for the fictional Republic of Narellia: a data page for Maro Selvane, Tidewarden of the Outer Reefs, with a consistent travel history through Korvath and Delmbria. Drawn programmatically with PIL (`render.py`); `main.ts` copies the rendered `entry.png` to `/output/entry.png`.

## Run it

```sh
python3 render.py   # regenerates entry.png (1024x1024)
node main.ts        # writes /output/entry.png
```
